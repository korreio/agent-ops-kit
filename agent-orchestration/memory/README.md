# External private memory

This directory ships guidance and an empty [LINKS](LINKS) template. It contains no private project memories and is not a synchronization target.

Optional Claude project-memory relocation uses an explicit absolute `--memory-root` outside the resolved toolkit checkout, plus one or more explicitly chosen `--memory` project paths. Same resolved populated stores are idempotent; a populated link cannot be retargeted to a different store. Two populated regular sides also refuse rather than merge.

Read [memory placement, refusal and recovery](../../docs/memory.md) before use. Keep one active writer per project, preserve all sides before manual migration, and make second-Mac copying a separate owner-directed workflow. The kit does not enroll its working checkout or actual memories in another transfer setup.
